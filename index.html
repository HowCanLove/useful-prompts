如何写好 AI 提示词？

同样的 ChatGPT / Claude / Gemini，懂提示词的人能让它写出可直接发布的公众号文章；不懂的人只能得到「我可以帮你想想……」的空话。差距不在模型，而在提示词结构：明确角色（「你是一位资深中文编辑」）+ 具体任务（「润色而不是重写」）+ 输出格式（「分点列出修改之处」）+ 边界（「保留专业术语和人名」）。

本目录精选 60+ 条经实测的 AI 提示词模板，按 写作 / 编程 / 翻译 / 学习 / 营销 / 创意 / 数据分析 / 求职 / 生活 分类。每条都附完整模板 + 一键复制按钮，覆盖 ChatGPT (GPT-4 / GPT-5)、Claude (Sonnet / Opus / Haiku)、Gemini 等主流大模型。

所有提示词均经过实际场景打磨——不是从 LinkedIn / Twitter 复制的「30 个 ChatGPT 提示词」泛泛之谈，而是为具体任务设计的可直接套用版本。涉及医生 / 心理 / 法律 / 财务等专业领域的提示词，均明确标注「沟通辅助 / 不替代专业人士」。
